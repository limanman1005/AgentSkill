# 🤖 AgentSkill

> 沉淀、分享、复用 —— 一个精选 Agent Skill 的开放仓库

[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

## 简介

本仓库用于收集和分享在实际项目中沉淀下来的 **Agent Skill**，包括提示词模板、工具调用配置、工作流示例等。希望通过开放共享，帮助更多开发者快速构建高质量的 AI Agent 能力。

## 📂 目录结构

```
AgentSkill/
├── skills/
│   ├── web-search/          # 网络搜索相关 Skill
│   ├── data-analysis/       # 数据分析相关 Skill
│   ├── code-assistant/      # 代码辅助相关 Skill
│   └── document-processing/ # 文档处理相关 Skill
├── SKILL_TEMPLATE.md        # Skill 贡献模板
└── CONTRIBUTING.md          # 贡献指南
```

## 🗂️ Skill 分类

| 分类 | 描述 |
|------|------|
| [网络搜索](skills/web-search/) | 搜索、检索、信息获取类 Skill |
| [数据分析](skills/data-analysis/) | 数据处理、分析、可视化类 Skill |
| [代码辅助](skills/code-assistant/) | 代码生成、审查、重构类 Skill |
| [文档处理](skills/document-processing/) | 文档解析、摘要、转换类 Skill |

## 🚀 快速开始

1. **浏览** 上方分类目录，找到你需要的 Skill
2. **复制** Skill 配置到你的 Agent 项目中
3. **按需调整** 参数，适配你的业务场景

## ✨ 贡献 Skill

欢迎提交你自己沉淀的 Agent Skill！请参阅 [贡献指南](CONTRIBUTING.md) 和 [Skill 模板](SKILL_TEMPLATE.md)。
